# PDFTools beta: what's new (November 2026)

Thank you for your review of the beta. This update is built from your feedback. Everything still
works offline, and your documents never leave your device.

## Getting around

- **PDFTools** and its icon at the top left, a **Home** button to openengtools.com and a
  **Report an Issue on GitHub** button (it opens GitHub in a new tab and sends nothing by itself;
  please don't attach confidential documents).
- **Full Screen** (top right, or Ctrl+Shift+F11) shows the whole app full screen; Esc leaves.
- **Snapping** in the status bar is now a magnet button.
- **The ribbon adapts to your window:** full labels on wide screens, icons only when it is
  narrower, then group menus.
- **Home** now has Snapshot, Properties, rotate the view both ways, and more comment tools
  (rectangle, arrow, callout, line).

## Comments

- **Right-click menus** on comments, on the page, in the Comments pane and in the Bookmarks pane.
  **Cut, Copy and Paste** comments with the menu or Ctrl+X / Ctrl+C / Ctrl+V; Paste from the menu
  puts them where you clicked.
- **New default look:** red, 1 pt lines and 10 pt text (highlights and sticky notes stay yellow).
  Make Current Properties Default (right-click) sets your own.
- **Style palette** next to each drawing and text tool, with preset colours and your own styles
  (Comment Styles Palette… to add, rename, export and import them).
- **Comments pane:** comments as cards with room to read them; sort, group and filter under
  Options; reply right in the card.
- **Properties pane** shows every property of the selected comment: subject, author, dates,
  Printable, Read only, Locked, Marked and its review history; fill, stroke, line style and width,
  opacity, blend mode and rotation; font, size, bold, italic and alignment.
- **Attach File** puts a file on the page as a paperclip comment (up to 25 MB).
- **Flatten Comments** makes comments part of the page (all of them or the selected ones).
- **Snapshot** copies an area of the page to the clipboard as a picture.

## Bookmarks

- **Edit bookmarks** in the Bookmarks pane: new bookmark from the current view, new child, rename
  (F2), delete, cut / copy / paste, drag to move (or Alt+Shift+arrows), set destination, and
  Bookmark Properties for the title, colour, bold, italic, page and zoom.

## Forms

- **A new Form tab** to make forms: text fields, check boxes, radio buttons, list boxes and
  dropdowns. Set each field's name, tooltip, default, items and look in the Properties pane, and
  the page's tab order. Select Fields moves and resizes them; Highlight Fields shows or hides
  their tint; Reset Form restores the defaults. PDFTools never adds scripts to a form.

## Protect

- **Password Security** saves a copy with a password to open it, a permissions password that
  restricts printing, changes and copying, or both (AES-256). **Remove Security** saves a copy
  without them. Both need the owner password of a file that is already protected.
- **Sign Document** places a signature or initials that you draw, type (in a handwriting font) or
  upload as a picture. You can save it on this device for next time. This is a **visual
  signature**, not a certificate-based digital signature; that comes later.

## Good to know

- Help → Help describes every new feature, and Help → Keyboard Shortcuts lists every key.
- Styles, saved signatures and your reviewer profile stay on this device. File → Settings →
  Clear all local data removes them.
- Form fields and comments made here are standard PDF objects. We are checking them in Adobe
  Acrobat Reader and PDF-XChange; if something looks different there, please report it.
- Known limits: a comment's rotation and a text box's vertical alignment may be lost if another
  viewer redraws the comment; with an open password only, anyone who opens the file can change
  its security.
