Found and fixed during this pass:

- **Ctrl+S (and Ctrl+O/P/F) did nothing inside a text field** (a form field, the find box): the
  keymap swallowed every shortcut while typing, so the browser's "Save page" took Ctrl+S. These
  chords now work in text fields (`inText` in the keymap), and a form field commits its value
  first.
- **A save could overtake the form value typed just before it** (the value is committed
  asynchronously). Saves, prints and print-ready exports now wait for form edits in flight
  (`src/features/save/pendingEdits.ts`).
- **Home → Select Text** had no handler: it now selects text like Select (and stays text-only when
  M3 gives Select objects).
