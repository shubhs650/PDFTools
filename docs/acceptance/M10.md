M10, the visual refresh, is **complete on the agent side**. Every task of the plan (M10-01 …
M10-07) and all nine optional items the owner accepted (O1 … O9) are merged, each with its own
tests (section 2). Every point of the review maps to a task or to the reason we did not follow it
(section 1). This task adds the full screenshot set, an accessibility sweep of M10's new surfaces
in four variants, the regenerated Help screenshots, the install-budget figures and four fixes
found while taking the screenshots (section 4). What only the owner can judge (the look on real
screens) is in the **owner pack** (section 6). Release notes for beta users:
[docs/release-notes/beta-m10.md](../release-notes/beta-m10.md); the same release is the newest
entry of File › About › What's new (`src/i18n/whatsnew.en.json`).

## 4. Found and fixed during M10-09

All four came from the screenshot review; three only show in Windows High Contrast (forced
colours), where the `--color-selected-text` token maps to `HighlightText`, meant for a Highlight
fill.

- **High Contrast: the current page in Thumbnails had no number.** Its label sits on the plain
  pane in `HighlightText`, white on white. It now takes `Highlight`. Test: `e2e/theme.spec.ts`
  "forced-colors: the current thumbnail number and the chosen Tell me result stay readable".
- **High Contrast: Tell me's chosen result was a blank box.** The browser's text backplate
  (Canvas) hid its `HighlightText` label. The row keeps its Highlight pair as drawn
  (`forced-color-adjust: none`), as the File tab does since M10-02. Same test.
- **High Contrast: the start screen's hint while dragging files** had the same white-on-white
  text; the card stays on Canvas with a Highlight border and the hint takes `Highlight`.
- **Comments pane with no comments said "No comments in this document." twice** (in the list
  and in the count line under it). The count line stays mounted (it is a live region) but is
  empty and takes no room until there are comments.

## 5. Known limits carried forward

- **Install budget:** 60.51 MB against the 60 MB reference (a reference only); core 0.84 MB below
  its 9 MB budget.
- **Ribbon small buttons** stay 24 px (R18; WCAG 2.2 SC 2.5.8 minimum), also in Compact.
- **Accent and density** are kept per device, like the theme; they do not travel between
  browsers.
- **What's new** shows once per device after an update; a device that clears its data sees no
  banner for the release it then has (the release is recorded quietly).
- The M7 and M6 limits are unchanged ([M7 acceptance](M7.md) §4).
