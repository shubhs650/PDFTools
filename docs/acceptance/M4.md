Found and fixed during M4-22:

- **A redaction across the middle of a line failed verification.** PDFium removes the covered
  glyphs but keeps the rest of the line in one text object whose bounds still span the mark, so the
  "text objects" check reported a leak with nothing inside (found by the M4 offline proof). A text
  object now counts only if one of its own characters lies inside an area
  (`FPDFText_GetTextObject`); objects the text page does not index keep the bounds rule; the
  character and string checks are unchanged. Regression test with a negative control in
  `tests/redact/apply-integration.test.ts`.

## 3. Decisions and open items carried forward

- **First-open perf task at the limit** (`perf/open.spec.ts`, 103–113 ms on CI): proposed fix
  needs the owner (start the Render engine at idle after boot; changes ADR-004's lazy start). See
  `docs/PROGRESS.md`, Open issues.
- **ADR-016 decision 7 leftovers** (M4-09): orphaned form fields after deleting all their widgets
  stay in `/AcroForm /Fields` (valid PDF), no page-labels note in the Delete dialog, bookmarks to a
  deleted page are not marked "target page deleted".
- **Comment transfer:** JSON-imported measurements arrive as plain markups (import from the PDF
  keeps `/Measure`); Copy/Paste Comments have no context menu yet (ribbon and keys).
- **Tables and Word are Beta** (D-31): detection quality on real pipe charts and parts lists is
  untested beyond the self-made fixture until the owner run (4.3).
- **Redaction limits by design:** a crossing line inside a Form XObject cannot be re-cut, so such a
  page fails verification and nothing is written (the user is told which page); OCR-only (scanned)
  content has no text to remove: its image pixels inside the area are removed.

## 5. Public-beta readiness (D-32)

The Rev 0 feature set is complete on the agent side. These items block the public beta; each
needs the owner (decision, account or machine):

1. **Interop runs, M1–M4** (§12 "Round-trip"): the checklists §A–§M4 in Acrobat Reader and
   PDF-XChange, both directions. This §12 row can only be met on the owner's machines.
2. **Heavy-file and reference-machine runs** (§12, ADR-002): `npm run owner:timings` on the FAR,
   the ~500 MB contract and the dense A0/P&ID drawings; memory with 5 heavy tabs (< 2 GB).
3. **Hosting:** the Cloudflare Pages project (S8 preview, header and CSP check on the real host,
   server-side analytics only), the `/api/report` D1 database and optional e-mail binding
   (`docs/deploy/error-report.md`).
4. **Committed corpus PDFs** (Decisions needed 1): `bearing catalogue.pdf` is a copyrighted
   catalogue and must leave git (and history) before the repository or the beta is public.
5. **First-open perf task at the limit** (section 3): decide the idle engine start (ADR-004) so
   the "no task > 100 ms, ever" row is clean on CI.
6. **Keyboard text selection** (M2-04): accept Ctrl+A + copy as the keyboard path for the beta, or
   schedule caret selection (about one session).
7. **Open ADR-007 decisions 2 and 3** (measurement labels, viewport semantics): from the interop
   run (§D/§F).
8. **Firefox check** (S8, still open): the app targets Chromium/Edge (File System Access); decide
   which browsers the beta announces and run the S8 Firefox check for the ones it names.

Not blocking (known limits, documented for beta users): Word and tables are Beta; ADR-016 d7
leftovers; JSON-imported measurements are plain markups; markups do not show in thumbnails; the
redaction limits in section 3.
