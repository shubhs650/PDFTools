## 2. What M13-09 changed

- **Help:** five new topics — _Thin Lines_ and _Previous view and next view_ (Viewing and
  finding), _The loupe and automatic snapping_ (Measuring), _Comment review sheets (CRS) and
  project templates_ (Comments and markup), _Trying a sample comparison_ (Compare revisions) —
  and links to them from Zoom, Snapping, Measuring, Starting a comparison and Reviewing comments.
  Snapping now names the labelled **Enable Snapping** button, Alt for a point that does not snap
  and automatic snapping; Measuring says a distance ends in open arrows. **Every** Help picture
  was made again with `npm run help:screenshots` (73, 7 new) and each topic re-read against them.
- **The loupe's key, M** (document scope, D-29): shows or hides the loupe in the tool in use —
  the Measure ribbon's Loupe in the tools it serves (Measure, Calibrate, Scale Viewport, the line
  comments), View › Loupe in any other (`toggleLoupeHere`, unit-tested; both Loupe commands
  name M wherever the app shows a command's keys, such as a folded ribbon's tooltip). Decided here: one key that always flips what the person sees, rather
  than a key for each switch.
- **Shortcut sheet:** a second part, _Keys in a pane or window_, lists the keys a pane or window
  reads with its own listener (`src/app/keys/windowKeys.ts`): Space and Z held, Alt while
  clicking, F8 / Shift+F8 in a comparison, X held in an overlay, M / U / H / Insert in Review &
  Extract. `tests/keys/everyKeyListed.test.tsx` checks every chord of every binding is on the
  sheet, every window key has a row, and scans `src/` for a listener comparing a key the sheet
  does not list. Ctrl+5 and Ctrl+Alt+5, Alt+Left and Alt+Right, M are named in the test.
- **About:** version 1.1.0 (since M12-22). No dependency was added in M13, so the license list
  and third-party notices built from the lockfile are unchanged apart from versions
  (`npm run licenses`: all 776 packages comply).
- **What's new 1.1.0** now covers M13 too (samples, the loupe, Thin Lines, Previous / Next View,
  CRS in the project's Excel form), dated 2026-11-24; `e2e/whats-new.spec.ts` constants and a
  unit test updated. [Release notes](../release-notes/v1.1.0.md) have the M13 sections.
- **Compare on in release builds:** `VITE_COMPARE: 'off'` removed from
  `.github/workflows/release.yml` (the switch stays in the code for a later preview feature;
  `docs/deploy/release.md` says so).
- **README:** a Compare row, Thin Lines, Previous / Next View, the loupe and CRS templates in the
  features table; the What's new link points at v1.1.0.

## 4. Owner pack

M13-10 (Shubham, 2026-11-24: Distance, Perimeter and Area placed by clicks, with the dimension
line set sideways) is in; its line is in What's new and the release notes.

Pictures: project files `m13-09/` (the new Help pictures and the shortcut sheet) and `m13-10/`
(measuring by clicks).

- [ ] **Samples:** Compare › PDF Overlay → Try a sample → each of the two; then Text Comparison →
      each of the two. The start screen's "Try comparing two revisions" opens the flange sample.
- [ ] **Loupe:** Measure › Distance on one of your drawings: the loupe beside the pointer with
      the snap point and its kind; snapping turned on by itself and back off after Esc. Press M
      to hide and show it. View › Loupe with Select. File › Settings › Measure: size and
      magnification.
- [ ] **Measuring by clicks:** Measure › Distance on one of your drawings: click one point,
      release, click the second, move sideways (the dimension line and its leader lines follow),
      click to place. Esc while placing drops it; Enter places it where it is. Perimeter and
      Area: click each point, double-click or Enter (Area also on its first corner). Save, then
      open the file in another PDF viewer: the dimension line sits where you put it, with its
      leader lines and arrows.
- [ ] **Thin Lines:** a dense drawing of yours at 400 %: Ctrl+Alt+5 (Ctrl+5 in the installed app),
      the status bar button and View › Thin Lines. Save, print: the file's own lines.
- [ ] **View history:** type a page, click a bookmark, switch tabs, then Alt+Left / the status
      bar's left arrow walks back through them, Alt+Right forward.
- [ ] **A real project CRS template:** Comment › Export CRS → Templates… → Import Excel form…
      with your project's own empty form; check the suggestions, place any missing field by
      clicking the sheet, Save template; export for one or two of your documents and **open the
      result in Excel** (no repair prompt, rows, formulas, drop-downs and the sign-off block as
      expected).
- [ ] **Help:** skim the five new topics (Help › Help, or F1) and Help › Keyboard Shortcuts.
- [ ] **Release:** merge, try the beta site, then tag `v1.1.0` on the merge commit and approve
      the deploy ([docs/deploy/release.md](../deploy/release.md)). If the release day is not
      2026-11-24, change the date of `v1.1.0` in `src/i18n/whatsnew.en.json` first (or ask).
