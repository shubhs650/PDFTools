## 2. What M14-11 changed

- **Help:** the Measuring chapter has eight new topics — _Scale viewports_, _Volume, cutouts
  and area units_, _Angle, radius and diameter_, _Counting items_, _Changing a measurement_,
  _The Measurements pane_, _Exporting measurements_, _Measurements in other PDF viewers_ — and
  _Setting the scale_, _Measuring length, perimeter and area_ (was "distance"), _Snapping_ and
  _The loupe_ are rewritten for the ten tools (Shift, view changes while measuring, labels and
  captions, the no-scale question, scale changes). Welcome, the Home tab and Reviewing comments
  name the new parts. **Every** Help picture was made again with `npm run help:screenshots`
  (10 new: `measure-tools-4`, `scale-viewports-1`, `measure-volume-1`, `measure-curves-1`,
  `measure-count-1`, `measure-editing-1`, `measurements-pane-1`, `measure-export-1` and `-2`;
  the Measure tab picture shows its new groups). The measuring pictures are drawn on the
  measure corpus with the real tools (`e2e/help-shots/measureScenes.ts`).
- **Shortcut sheet:** _Keys in a pane or window_ lists **Shift** held while measuring (the next
  point at 0°, 45° or 90°, still snapping; `lockAngle` in `windowKeys.ts`). The other M14 keys
  (arrow keys, Delete, Enter on a point or viewport) are the sheet's existing "move selected"
  and navigation keys. Settings › Measure's note names the tools that turn snapping on.
- **Version 1.2.0** in `package.json` (About shows it). No dependency was added in M14-11.
- **What's new 1.2.0** at the top of `src/i18n/whatsnew.en.json`, dated 2026-11-28;
  [release notes](../release-notes/v1.2.0.md); `e2e/whats-new.spec.ts` constants and the unit
  test updated. README: the Measure row, the What's new link and the measure picture.
- **Owner pack file:** `e2e/measure-owner-pack.spec.ts` builds one PDF from the measure corpus
  floor plan (1 : 100) and pipe run (1 : 50) with the real tools and saves it the Ctrl+S way,
  verified and checked by `qpdf --check`. With `M14_OWNER_PACK_OUT` set it writes
  `M14_owner_pack.pdf` there (project files `M14-11/`). Page 1: seven counts (Door), a Length
  with its dimension line set sideways, a Length with its caption In line, a Polylength, a
  Perimeter, a labelled Area (Workshop), a Volume with two cutouts (17.69 m³ net) and the
  summary table of all pages. Page 2: a Length, a Polylength, an Angle (37.5°), a Radius drawn
  as a full circle (R 300 mm), a Radius by three points drawn as its arc (R 1,200 mm) and a
  Diameter (Ø 3,000 mm). The Excel export (with pictures) is attached.

## 4. Owner pack

Pictures: project files `M14-11/` (the new Help pictures) and `M14-03/` … `M14-10/`. The test
file: project files `M14-11/M14_owner_pack.pdf`.

**Done means (plan §11, Q35):** the test file, opened in **Adobe Acrobat Reader**, **the second
desktop editor** (the one used for the FDF exports) and **the PDF viewer in Chrome or Edge**:
every measurement looks right, selects, moves and deletes as one item, and its value can be
read. Bluebeam Revu is not a required viewer (D-33).

- [ ] **Acrobat Reader:** open `M14_owner_pack.pdf`. On both pages every measurement shows its
      value; click each one: one item is selected (not a line and a separate text box); move
      one and its value stays with it; delete one and nothing is left behind. The comment list
      shows the values as text with Length, Area, Count … as subjects. The attachment
      `M14_owner_pack (Measurements).xlsx` opens.
- [ ] **The second desktop editor:** the same checks. Note any measurement whose caption
      disappears after a move (the value must still be in its text).
- [ ] **Chrome or Edge viewer:** every measurement and the summary table show as in Triya PDF.
- [ ] **Excel:** open the attached workbook (and `M14-10/sample-measurements.xlsx`): no repair
      prompt; the Measurements sheet has one row each with real numbers and pictures; Totals has
      one row per group. _(Pending from M14-10.)_
- [ ] **In Triya PDF:** open the file again; the Measurements pane lists 19 measurements with
      totals; drag a point of the Polylength, Undo; Renumber after deleting Door 3; try each
      tool once on one of your own drawings, and Same-Size Count Numbers in the status bar.
- [ ] **Help:** skim the Measuring chapter (Help › Help, or F1 on the Measure tab) and Help ›
      Keyboard Shortcuts.
- [ ] **Decision (from M14-07):** with 1,000 count symbols on one sheet, each click and each
      zoom redraws every comment of the page (~80–150 ms a click, ~200 ms a zoom; EmbedPDF draws
      all of a page's comments again on each change, for any kind of comment). Ship 1.2.0 as it
      is with a follow-up issue, or hold the release for it.
- [ ] **Release:** merge, try the beta site, then tag `v1.2.0` on the merge commit and approve
      the deploy ([docs/deploy/release.md](../deploy/release.md)). If the release day is not
      2026-11-28, change the date of `v1.2.0` in `src/i18n/whatsnew.en.json` first (or ask).
