## 3. Owner pack

Everything here runs on the owner's Windows machine. Setup, once, in PowerShell in a clone of
the repository: `npm ci`, then `npx playwright install chromium` (for the scripted timings).

Record the results in `docs/PROGRESS.md` (or send them to the agent), then tick the item.

### 3.1 Heavy files: FAR, the ~500 MB contract, dense A0 drawings and P&IDs

```powershell
npm run build:e2e
$env:E2E_SKIP_BUILD="1"
$env:OWNER_PDF="C:\path\far.pdf;C:\path\contract-500mb.pdf;C:\path\a0-drawing.pdf"
npm run owner:timings
```

For each file this prints and saves `reports/owner-<n>.json`:

- first page and first sharp view;
- scroll at 900 and 3,000 px/s (blank page frames, frame gaps);
- sharp tiles after zooming to 800 %, 6400 % and 100 %, including progressive-render slices;
- Ctrl+S with 100 markups and the bytes appended;
- any main-thread task > 100 ms.

The files are read from disk and never copied into the repository. No file names are recorded.
To watch it run, add `--headed` (`npm run owner:timings -- --headed`).

- [ ] FAR: numbers recorded.
- [ ] ~500 MB contract: numbers recorded (Ctrl+S copies the whole file in Chrome — ADR-005, open
      issue).
- [ ] Dense A0 drawings and P&IDs: numbers recorded.
- [ ] The earlier low-end-machine question (M1-15): a first open with no long task > 100 ms.

### 3.2 Installed app on Windows (Edge)

Build and serve the production app locally: `npm run build`, then `npm run serve` (it prints the
address; `localhost` counts as secure, so the app can be installed).

- [ ] Edge → the address → "Install PDFTools". The app window opens.
- [ ] File handler, **closed** app: in Explorer, right-click a PDF → Open with → PDFTools. It
      opens in a tab.
- [ ] File handler, **running** app: open a second PDF the same way. It joins the same window as a
      new tab.
- [ ] Offline: wait for "✓ Ready offline", close the app, turn off the network (or stop
      `npm run serve`), start the app from the Start menu, open a PDF, save it.
- [ ] Update: with the app installed, change anything, rebuild (`npm run build`), restart
      `npm run serve`. Help → Check for Updates shows "An update is ready". "Update ready" waits
      while a document is open.
- [ ] Reserved keys: `npm run build:e2e`, then `node scripts/serve.ts --root dist-e2e`, open
      `/?keyprobe` in Edge (as a tab **and** installed), and press Ctrl+W, Ctrl+F4, Ctrl+Tab,
      Ctrl+PageUp/PageDown and their alternates (Ctrl+Alt+W, Ctrl+Alt+PageUp/PageDown). Note which
      reach the page (M1-11, M1-Q1).
